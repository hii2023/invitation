# Digital Wedding Invitation — Heena & Azaz

A beautiful **animated digital wedding invitation** website for the Nikah and Daawat (reception) of Heena & Azaz in Ahmedabad — with separate invitation pages for each guest tier and an interactive wishes wall.

## What It Does

Delivers a personalized wedding invitation experience to each guest group — family, friends, and relatives each see a page tailored to them — while guests can also leave digital wishes.

## Key Features

- **Daawat-e-Khaas page** — exclusive invitation for close family
- **Friends & Family (FNF) page** — invitation for friends and close circle
- **Relatives page** — invitation for extended family
- **Wishes wall** (`wishes.html`) — guests can write and read wedding wishes
- **Countdown timer** — live countdown to the wedding day
- **Particle animation effects** — floating particles for a festive feel
- **Background music toggle** — Islamic/celebratory background music with on/off control
- **Islamic-themed design** — minarets and clouds visual elements
- **Ahmedabad skyline** — localized visual touch
- **Admin panel** (`admin.html`) — manage wishes and event details
- **Mobile-first design** — works perfectly on all phones

## Tech Stack

- HTML, CSS, Vanilla JavaScript
- CSS particle animations
- HTML5 Audio API

## Pages

| File | Purpose |

## Audience

Wedding guests of Heena & Azaz; event organizer for wishes moderation.
